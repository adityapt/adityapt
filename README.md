## Featured open-source work

### causalgeo — concurrent geo holdouts

Python package for concurrent geo experiments where several channel bundles
are tested at once. It estimates bundle lift, provides a model-assisted channel
split only when the design and impression paths support it, and withholds
channel estimates when they cannot be identified.

[Repository](https://github.com/adityapt/causalgeo) ·
[PyPI](https://pypi.org/project/causalgeo/) ·
[Zenodo](https://doi.org/10.5281/zenodo.24041239)

### DeepCausalMMM

Open-source Python package for marketing-mix modeling with deep-learning
components and explicit causal structure. It supports temporal effects,
saturation, channel interactions, multi-region modeling, and budget
optimization.

[Repository](https://github.com/adityapt/deepcausalmmm) ·
[PyPI](https://pypi.org/project/deepcausalmmm/) ·
[JOSS paper](https://joss.theoj.org/papers/10.21105/joss.09914)

## Applied systems

### SAGE

AI copilot for interacting with marketing-mix models through natural language:
diagnostics, visualizations, constrained budget optimization, and
artifact-grounded explanations.

[Live demo](https://SAGEinsights.streamlit.app) ·
[Repository](https://github.com/adityapt/SAGE)

### Cerebro

Agentic system for generating, validating, and executing Bayesian MMM
workflows. It infers an MMM specification from data, then coordinates
exploration, preprocessing, modeling, diagnostics, optimization, and
visualization.

[Repository](https://github.com/adityapt/cerebro)

### llm-copilot

Experimental project for LLM-orchestrated analytical workflows: tool calling,
RAG over model outputs and benchmarks, scoped code execution, and integrations
with Databricks, Snowflake, and BigQuery.

[Repository](https://github.com/adityapt/llm-copilot)
